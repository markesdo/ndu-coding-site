# Deine Mappe

Deine Mappe aus dem Innolab – wird von der Werkstatt geschrieben.

Hier liegen deine Arbeitsergebnisse aus dem Kurs: Brief, Entscheidungen, Interviewleitfaden, Annahmen und was im Lauf des Innolabs dazukommt. Du bearbeitest sie in der Werkstatt auf der Kurswebsite, nicht direkt hier.

Die Übersicht (Stand und Liste aller Dateien) schreibt die Werkstatt bei jedem Speichern neu in diese Datei.
